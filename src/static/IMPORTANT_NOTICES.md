# TOPページの重要告知

`important-notices.json` を編集して、TOPページのロゴより上に重要告知を掲載できます。
既存の `alert.json` と更新履歴の `history.json` とは別に管理します。
見出し・要約・主要リンクは常に表示し、詳細本文と参考リンクは初期状態で折りたたみます。

```json
[
    {
        "id": "unique-notice-id",
        "enabled": true,
        "status": "warning",
        "date": "2026/11/03",
        "title": "重要なお知らせ",
        "summary": "必ず伝えたい要点と、利用者にお願いする対応を短く記載します。",
        "primaryLink": { "label": "ダウンロード", "url": "https://example.com/download" },
        "paragraphs": ["最初の段落", "次の段落"],
        "links": [
            { "label": "詳細はこちら", "url": "https://example.com/" }
        ]
    }
]
```

- `id`: 告知ごとに重複しない半角英数字・ハイフンのIDを指定します。
- `enabled`: `true` で表示、`false` で非表示になります。全件非表示または空配列 `[]` の場合、告知欄は表示されません。
- `status`: `error`（赤）、`warning`（黄）、`info`（青）、`success`（緑）から選びます。
- `date`: 掲載日・更新日の表示用です。公開予約や掲載終了日の指定ではありません。
- `title`: 告知の見出しです。
- `summary`: 常時表示する短い要約です。対象・対応内容・必要な期日をここに記載します。
- `primaryLink`: 任意項目です。ダウンロード先など、常時表示する主要リンクを1件指定できます。不要なら省略します。
- `paragraphs`: 本文を段落ごとに指定します。HTMLは使用せず、段落内の改行には `\n` を使えます。
- `links`: 任意項目です。リンクは別タブで開きます。リンクが不要なら省略または `[]` にします。

`paragraphs` と `links` は詳細内に表示されます。「詳細を表示」で展開し、「詳細を閉じる」で折りたたみます。
各告知は個別に開閉でき、見出し・要約・主要リンクは折りたたんでも残ります。

有効な告知はJSONの配列順ですべて表示されます。重要なものを先頭に置いてください。
自動的には掲載終了しません。掲載を終了する場合は `enabled` を `false` にしてください。

JSONはビルド時に読み込まれます。変更後は通常どおりビルド・デプロイしてください。
